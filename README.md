# Indian E-Commerce Sales Analysis | Power BI

Interactive 2-page Power BI dashboard analyzing sales, profitability
and customer behaviour of an Indian e-commerce business (2023-2025).

## Key Metrics
- Total Revenue: ₹245 Cr
- Total Profit: ₹19.7 Cr (8.05% margin)
- 100K orders | 25K customers | Avg Order Value: ₹24.5K

## Key Insights
- Electronics contributes ~50% of total revenue
- Maharashtra, Uttar Pradesh and Gujarat lead in order volume
- Profit margin is only 8.05%, so low-margin categories need attention
- Revenue shows a sharp rise in the latest months

## Tools Used
Power BI Desktop, DAX, Power Query

## DAX Measures
- Profit Margin % = DIVIDE([Total Profit], [Total Revenue])
- Average Order Value = DIVIDE([Total Revenue], [Total Orders])

## How to Use
Download `Indian E-commerce analysis.pbix` and open it in Power BI Desktop.
